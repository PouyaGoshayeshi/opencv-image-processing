# OpenCV Image Processing Projects

A collection of image-processing exercises developed with Python, OpenCV and NumPy. The repository demonstrates geometric transformations, gamma correction, noise generation, median filtering and colour-channel separation.

## Projects

### 1. Geometric Transformations

Applies image rotation and wave distortion using OpenCV transformation functions.

**Main file:** `geometric-transformations/image_transformations.py`

![Rotated image](geometric-transformations/rotated_output.jpg)

![Wave distortion](geometric-transformations/waved_output.jpg)

### 2. Manual Geometric Transformations

Creates transformation maps manually and uses `cv2.remap` to apply rotation, wave distortion and a combined transformation.

**Main file:** `manual-geometric-transformations/manual_transformations.py`
